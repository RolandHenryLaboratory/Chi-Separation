# Chi-separation Toolbox
This section mainly focuses on instructions for using the Chi-Separation Toolbox. It also includes a brief introduction to a one-line QSM processing script for CV-sequence data, in case cross-sectional comparisons are required for certain subjects. For more detailed information on QSM processing, please refer to the previously created repository for [QSM processing](https://github.com/RolandHenryLaboratory/QSM-reconstruction-and-crossectional-registration/tree/main). <br>

**Chi-Separation Toolbox required working enviorment:** <br>
&emsp;&emsp;**MATLAB: R2019b~2026b** <br>
&emsp;&emsp;**Operating System:Linux and Windows**

## Chi-Separation Toolbox
**1) Included External Packages :** <br>
- MEDI toolbox (for BET and Complex data fitting): http://pre.weill.cornell.edu/mri/pages/qsm.html
- STI Suite (for Background Field Removal-VSHARP): https://people.eecs.berkeley.edu/~chunlei.liu/software.html
- mritools (for ROMEO phase unwrapping): https://github.com/korbinian90/CompileMRI.jl/releases <br>

**2) Input data format :** <br>

Load multi-echo GRE input data. Select the input data format: DICOM or NIfTI (.nii). Click ‘Load’
button to open the folder selection window.
  - **For DICOMs:** <br>
  Select the folder that contains DICOM subfolders named <code>iMag</code> and <code>iPhase</code>, or <code>iComplex</code>. No other folders should be inside the selected folder except <code>iMag</code>, <code>iPhase</code>, or <code>iComplex</code>.
  - **For NIFTIs:** <br>
  For NIfTI input, select the magnitude and phase NIfTI files. If the corresponding json files (generated by dcm2niix) are loaded together, parameters are filled automatically. Otherwise, provide the parameters in the Parameters tab, either manually or by loading a <code>.mat</code> file.
