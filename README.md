# Chi-separation Toolbox
This section mainly focuses on instructions for using the Chi-Separation Toolbox. It also includes a brief introduction to a one-line QSM processing script for CV-sequence data, in case cross-sectional comparisons are required for certain subjects. For more detailed information on QSM processing, please refer to the previously created repository for [QSM processing](https://github.com/RolandHenryLaboratory/QSM-reconstruction-and-crossectional-registration/tree/main). <br>

**Chi-Separation Toolbox required working enviorment:** <br>
&emsp;&emsp;**MATLAB: R2019b~2026b** <br>
&emsp;&emsp;**Operating System:Linux and Windows**

Path to the Toolbox folder (available at Radology Server): `/data/henry17/jiuyi_datasets/Chisep_Toolbox_v1.2.1`

## Chi-Separation Toolbox
**1) Included External Packages :** <br>
- MEDI toolbox (for BET and Complex data fitting): http://pre.weill.cornell.edu/mri/pages/qsm.html
- STI Suite (for Background Field Removal-VSHARP): https://people.eecs.berkeley.edu/~chunlei.liu/software.html
- mritools (for ROMEO phase unwrapping): https://github.com/korbinian90/CompileMRI.jl/releases <br>

**2) Input data format :** <br>

Load multi-echo GRE input data. Select the input data format: DICOM or NIfTI (.nii). Click ‘Load’
button to open the folder selection window.
  - **For DICOMs:** <br>
  Select the folder that contains DICOM subfolders named <code>iMag</code> and <code>iPhase</code>, or <code>iComplex</code>. No other folders should be inside the selected folder except <code>iMag</code>, <code>iPhase</code>, or <code>iComplex</code>. <br>
  **Parameters:** Automatically loaded into the parameters section.
  - **For NIFTIs:** <br>
  For NIfTI input, select the magnitude and phase NIfTI files. If the corresponding json files (generated by dcm2niix) are loaded together, parameters are filled automatically. Otherwise, provide the parameters in the Parameters tab, either manually or by loading a <code>.mat</code> file. <br>
  **Parameters:** A pop-up window will appear and prompt you to import the JSON file.

**3) Pre-processed Optional Inputs:** <br>
This section applies only to R2*, R2′, tissue phase, QSM, and brain mask processing. <br>
- **Complex Image Fitting** <br>
A precompiled program for R2* fitting based on multi-echo magnitude images is included at the following path: `/data/henry17/jiuyi_datasets/Chisep_Toolbox_v1.2.1/functions/supportfunc/gsl_imFitting` <br>
`gsl_imFitting` fits multi-echo complex MRI data to estimate `S0`, `R2*`, off-resonance frequency, and initial phase.

```bash
gsl_imFitting <TE1,TE2,...ms> <mask.nii> <echo1_im.nii> <echo2_im.nii> ... <output_prefix>
```
- Convert NIFTIs to MAT file <br>

`Convert2mat` reads a NIfTI image, reorients it, and saves it as a `.mat` file using the variable name required by the χ-separation toolbox.

```matlab
Convert2mat(input_nii, outputpath, image_type)
```
#### Supported image types:

| `image_type` input | Variable saved in `.mat` |
|---|---|
| `R2_star` | `R2s` |
| `R2_prime` | `R2p` |
| `Tissue_phase` | `LocalField` |
| `QSM` | `QSM` |
| `Brain_mask` | `Mask` |

4) Workflow:
- **For Linux:** Open a terminal and load MATLAB:

  ```bash
  module load SCS/matlab/R2023b
  ```

  Then launch the MATLAB graphical interface:

  ```bash
  matlab
  ```

  After the MATLAB desktop opens, add the toolbox and all its subfolders to the MATLAB path (MATLAB Command Window):

  ```MATLAB
  addpath(genpath('/data/henry17/jiuyi_datasets/Chisep_Toolbox_v1.2.1'));
  ```
- **For Windows:** After downloading MATLAB and the χ-separation toolbox to your computer, open MATLAB and add the toolbox and all its subfolders to the MATLAB path:

  ```matlab
  addpath(genpath('C:\path\to\Chisep_Toolbox_v1.2.1'));
  ```
### Running the χ-Separation Toolbox

1. After adding the toolbox to the MATLAB path, launch the χ-separation interface from the MATLAB Command Window:

   ```matlab
   Chisep
   ```

2. Once the interface opens, import the required data as described in the previous section.

3. To generate a preprocessed `R2*` map from multi-echo complex data, run the following command in a terminal:

   ```bash
   /data/henry17/jiuyi_datasets/Chisep_Toolbox_v1.2.1/functions/supportfunc/gsl_imFitting \
     <TE1,TE2,...ms> <mask.nii> \
     <echo1_im.nii> <echo2_im.nii> ... \
     <output_prefix>
   ```

   The echo times must be provided in milliseconds, and the input echo images must follow the same order as the echo-time list.

4. Before importing preprocessed NIfTI images into the toolbox, convert them to the required `.mat` format using:

   ```matlab
   Convert2mat(input_nii, outputpath, image_type);
   ```

5. After loading all required images, select the directory where the processing results will be saved.

6. For the current pipeline, use the following processing methods:

   - **Phase unwrapping:** ROMEO  
   - **Background field removal:** V-SHARP  
   - **QSM reconstruction and susceptibility source separation:** Chi-Sepnet-R2*  
   - **R2* fitting:** Use the preprocessed `R2*` map when available; otherwise, select ARLO in the toolbox.

7. After processing is complete, export the intermediate variables stored in the `.mat` file as NIfTI images:

   ```matlab
   intermedia_export(input_mat, ref_nii, output_path);
   ```

   - `input_mat`: Path to the `.mat` file containing the intermediate variables.
   - `ref_nii`: Path to a verified reference NIfTI image whose header, affine, and orientation correctly match the original input.
   - `output_path`: Directory where the exported NIfTI files will be saved. The directory will be created automatically if it does not already exist.

   Example:

   ```matlab
   intermedia_export('result.mat', 'PCS.nii', './intermediate_outputs');
   ```

## Standalone QSM Processing for Single-Echo CV GRE Data

Most processing steps are the same as those described in the [QSM processing pipeline](https://github.com/RolandHenryLaboratory/QSM-reconstruction-and-crosssectional-registration/tree/main). The `qsm_recon` MATLAB function performs background field removal and dipole inversion for both multi-echo GRE (ME-GRE) and single-echo GRE (SE-GRE) data.

### 1. Launch MATLAB

Open a terminal and load the MATLAB module:

```bash
module load SCS/matlab/R2023b
```

Launch the MATLAB graphical interface:

```bash
matlab
```

### 2. Add the Function Directory

In the MATLAB Command Window, add the function directory and its subfolders to the MATLAB path:

```matlab
addpath(genpath('/data/henry17/jiuyi_datasets/Jiuyi_revision/functions'));
```

### 3. Run QSM Reconstruction

Run the following command in the MATLAB Command Window:

```matlab
qsm_recon(total_field_path, brain_mask_path, TE, output_path);
```

Inputs:

- `total_field_path`: Path to the total-field/Unwrapped phase NIfTI image.
- `brain_mask_path`: Path to the corresponding brain-mask NIfTI image.
- `TE`: Echo time used for the acquisition.
- `output_path`: Directory where the processing outputs will be saved.
